Retrato da produção · pacote C8

Absorção da produção

Passo a passo operacional para colher o retrato da produção: cada query abaixo é colada manualmente no DBeaver da produção, o resultado é exportado em CSV com o nome exato indicado e depositado na pasta certa. Esta página confere o depósito ao vivo.

Atenção

Estas queries rodam na PRODUÇÃO, no DBeaver, fora deste portal, manualmente. Nenhum botão desta página executa SQL em lugar nenhum: o botão só copia o texto. O servidor local fala apenas com a homolog GH e o Oracle TST, nunca com a produção.

Antes de começar

  • Produção é somente leitura manual no DBeaver. Nunca colocar credencial de produção no .env desta máquina.
  • Todas as queries são SELECT/WITH. Ordem de execução recomendada: bloco 00, depois 10, 20, 30, 40, por fim 99 (o 90 é opcional, a qualquer momento).
  • Export sempre em CSV UTF-8, separador vírgula, valores com aspas duplas quando necessário, com linha de cabeçalho (mesmo formato dos CSVs já commitados do C2).
  • O nome do arquivo é contrato: atlas.html, insights.html e esta página referenciam os nomes literalmente. Mudar um nome quebra a hidratação das páginas.
  • Duas camadas de destino: ana/api-mv/absorcao-producao/resultados/ é a camada commitável (entra no git); resultados/amostras/ fica fora do git. Qualquer resultado com dado de paciente vai para amostras/. Em dúvida, amostras.
  • Exceção única de dado pessoal: o paciente-sonda TESTE INTEGRACAO ANA VITTA (CPF 66301102770, id 1681), cadastro fictício de teste. Só ele pode aparecer em query e CSV commitável (query 10-5, que ainda protege com guarda qualquer colisão com paciente real).
  • Clone novo desta máquina: a pasta amostras/ é ignorada por inteiro pelo git, então crie-a localmente antes do primeiro export.

Camada: commitável · CSV de saída: 10-1-funil-ocupacao-mensal.csv em resultados/

queries/10-1-funil-ocupacao-mensal.sql
-- 10-1: funil mensal (marcado, compareceu, atendido) e ocupacao de agenda, 24 meses
-- Bloco 10: nucleo assistencial
-- Saida: 10-1-funil-ocupacao-mensal.csv (camada commitavel, resultados/)
-- Responde: insights 1, 3, 4, 5 (no-show, lead time, ocupacao, funil);
--   volume mensal real da producao; GH-19 (contexto de massa)
WITH funil AS (
  SELECT TRUNC(ac.DT_AGENDA, 'MM')                                    AS mes,
         COUNT(*)                                                     AS slots_com_paciente,
         SUM(CASE WHEN iac.TP_SITUACAO = 'C' THEN 1 ELSE 0 END)       AS cancelados,
         SUM(CASE WHEN iac.SN_ATENDIDO = 'S' THEN 1 ELSE 0 END)       AS atendidos,
         SUM(CASE WHEN iac.TP_PRESENCA_FALTA = 'P' THEN 1 ELSE 0 END) AS presencas,
         SUM(CASE WHEN iac.TP_PRESENCA_FALTA = 'F' THEN 1 ELSE 0 END) AS faltas,
         SUM(CASE WHEN iac.CD_ATENDIMENTO IS NOT NULL THEN 1 ELSE 0 END) AS com_atendimento,
         ROUND(AVG(ac.DT_AGENDA - iac.DT_GRAVACAO), 1)                AS lead_time_medio_dias
  FROM   DBAMV.IT_AGENDA_CENTRAL iac
  JOIN   DBAMV.AGENDA_CENTRAL ac
         ON ac.CD_AGENDA_CENTRAL = iac.CD_AGENDA_CENTRAL
  WHERE  iac.CD_PACIENTE IS NOT NULL
    AND  ac.DT_AGENDA >= ADD_MONTHS(TRUNC(SYSDATE, 'MM'), -24)
  GROUP BY TRUNC(ac.DT_AGENDA, 'MM')
),
ocupacao AS (
  SELECT TRUNC(ac.DT_AGENDA, 'MM')       AS mes,
         SUM(ac.QT_ATENDIMENTO)          AS capacidade,
         SUM(ac.QT_MARCADOS)             AS marcados,
         SUM(ac.QT_ENCAIXES_MARCADOS)    AS encaixes_marcados
  FROM   DBAMV.AGENDA_CENTRAL ac
  WHERE  ac.DT_AGENDA >= ADD_MONTHS(TRUNC(SYSDATE, 'MM'), -24)
  GROUP BY TRUNC(ac.DT_AGENDA, 'MM')
)
SELECT COALESCE(f.mes, o.mes)  AS mes,
       f.slots_com_paciente,
       f.cancelados,
       f.atendidos,
       f.presencas,
       f.faltas,
       f.com_atendimento,
       f.lead_time_medio_dias,
       o.capacidade,
       o.marcados,
       o.encaixes_marcados
FROM   funil f
FULL OUTER JOIN ocupacao o ON o.mes = f.mes
ORDER BY 1;

-- 10-5: teste GH-18. O paciente-sonda criado via API homolog existe na PRODUCAO?
-- Bloco 10: nucleo assistencial
-- Saida: 10-5-sonda-gh18.csv (camada commitavel, resultados/)
-- Responde: GH-18 CRITICA (para qual banco MV a homolog GH aponta)
-- Interpretacao: linha CPF_SONDA com nm_paciente TESTE INTEGRACAO ANA VITTA = a homolog GH
--   enxerga e grava na producao (grave, avisar imediatamente).
-- Linha CPF_SONDA com o nome oculto pela guarda = o CPF esta ocupado por OUTRO paciente real (colisao de
--   CPF valido, nao prova integracao; investigar antes de concluir).
-- Nenhuma linha CPF_SONDA = ambientes distintos (esperado).
-- Nenhum ramo expoe nome de paciente real: a guarda CASE omite o nome quando nao for a sonda.
SELECT 'CPF_SONDA'          AS verificacao,
       TO_CHAR(CD_PACIENTE) AS cd_paciente,
       CASE WHEN NM_PACIENTE = 'TESTE INTEGRACAO ANA VITTA'
            THEN NM_PACIENTE
            ELSE 'CPF OCUPADO POR OUTRO PACIENTE (nome omitido)' END AS nm_paciente,
       CASE WHEN NM_PACIENTE = 'TESTE INTEGRACAO ANA VITTA'
            THEN DT_CADASTRO
            ELSE CAST(NULL AS DATE) END AS dt_cadastro
FROM   DBAMV.PACIENTE
WHERE  NR_CPF = '66301102770'
UNION ALL
SELECT 'ID_1681',
       TO_CHAR(CD_PACIENTE),
       CASE WHEN NM_PACIENTE = 'TESTE INTEGRACAO ANA VITTA'
            THEN NM_PACIENTE
            ELSE 'OCUPADO POR OUTRO PACIENTE (nome omitido)' END,
       CASE WHEN NM_PACIENTE = 'TESTE INTEGRACAO ANA VITTA'
            THEN DT_CADASTRO
            ELSE CAST(NULL AS DATE) END
FROM   DBAMV.PACIENTE
WHERE  CD_PACIENTE = 1681;

       ROUND(100 * SUM(ac.QT_MARCADOS) / NULLIF(SUM(ac.QT_ATENDIMENTO), 0), 1) AS pct_ocupacao
FROM   DBAMV.AGENDA_CENTRAL ac
LEFT JOIN DBAMV.PRESTADOR p ON p.CD_PRESTADOR = ac.CD_PRESTADOR
WHERE  ac.DT_AGENDA >= ADD_MONTHS(TRUNC(SYSDATE), -6)
  AND  ac.SN_ATIVO = 'S'
GROUP BY ac.CD_PRESTADOR, p.NM_PRESTADOR
ORDER BY pct_ocupacao NULLS LAST, capacidade DESC;

-- 30-2: volume mensal por tipo de atendimento e internacao, com tempo medio ate a alta
-- Bloco 30: internacao, leitos e urgencia
-- Saida: 30-2-internacao-urgencia-mensal.csv (camada commitavel, resultados/)
-- Responde: insights 9 e 10 (tempo ate a alta, pressao da urgencia);
--   C6-2 (interpretacao de TP_ATENDIMENTO com volume real)
-- Nota: o significado de cada TP_ATENDIMENTO (U, E, A...) ainda depende da C6-2;
--   aqui medimos o volume real de cada valor
SELECT TRUNC(a.DT_ATENDIMENTO, 'MM') AS mes,
       a.TP_ATENDIMENTO,
       a.SN_INTERNADO,
       COUNT(*) AS qtd,
       ROUND(AVG(a.DT_ALTA - a.DT_ATENDIMENTO), 2) AS dias_ate_alta_medio,
       SUM(CASE WHEN a.SN_OBITO = 'S' THEN 1 ELSE 0 END) AS obitos
FROM   DBAMV.ATENDIME a
WHERE  a.DT_ATENDIMENTO >= ADD_MONTHS(TRUNC(SYSDATE, 'MM'), -24)
GROUP BY TRUNC(a.DT_ATENDIMENTO, 'MM'), a.TP_ATENDIMENTO, a.SN_INTERNADO
ORDER BY 1, 2, 3;
