O fluxo inteiro da Ana em raias por jornada, com cada nó ancorado no trecho literal do prompt que o define.

Este mapa retrata um prompt congelado

Carregando a versão retratada.

A página não fala com a plataforma: ela guarda, em cada nó, o trecho literal do prompt que originou aquele passo. A re-validação é feita por uma sessão Claude, que reexporta o prompt do agente pelo MCP do fazer.ai e procura cada trecho como texto exato. Trecho que não for encontrado é um nó defasado, e o prompt mudou naquele ponto.

Regra prática: se alguém editou o prompt na plataforma depois da data acima, trate o mapa como suspeito até rodar a re-validação.
