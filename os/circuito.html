O mecanismo, de ponta a ponta

Quem orquestra a Ana é a plataforma fazer.ai agents (agente id 1, tenant vitta-tech). Não existe LangChain nem n8n no circuito: a plataforma monta o turno com o prompt e o histórico, chama o gpt-5-mini, executa as ferramentas que o modelo pedir e grava o trace no Langfuse.

Esta página explica; ela só pergunta à plataforma onde cada ferramenta aponta. Os exemplos são reais e estáticos, capturados das provas registradas no roadmap. Para ver acontecendo ao vivo: Global Health (as cadeias, elo a elo). As jornadas do SOP em mapa: Mapa do SOP.

Como as peças se conectam
