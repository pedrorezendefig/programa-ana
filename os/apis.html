Mapa das APIs

A API GH de agendamento WhatsApp organizada por tema, com o selo do que dá e do que não dá para testar. Ela é puramente de agendamento: não é janela de leitura do banco MV (quem lê o MV é o Oracle TST na bancada, e o Atlas para produção).

Por que "criei e não achei no banco"

Fato de arquitetura confirmado pela MV (Dácilla, 24/jul/2026): a API roda sobre um banco da Global Health que o hospital não enxerga. Só a finalização grava no Oracle.
